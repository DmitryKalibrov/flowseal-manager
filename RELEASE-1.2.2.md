# Flowseal Manager v1.2.2 — устойчивый запуск Telegram-прокси

Обновление исправляет падение TG WS Proxy при заполненном системном диске и исключает ложное сообщение об успешном запуске.

## Что нового

- перед запуском TG WS Proxy проверяется наличие места для его временной распаковки;
- если системная временная папка переполнена, менеджер использует собственную папку на доступном локальном диске;
- `TEMP` и `TMP` меняются только для дочернего процесса прокси, системные настройки Windows не затрагиваются;
- успешный запуск подтверждается по локальному порту прокси, а не по краткому появлению процесса;
- состояние карточки Telegram различает работающий прокси и зависший процесс без доступного порта;
- при нехватке места показывается понятное сообщение на русском языке.
- установщик предлагает включить штатный режим автонастройки TCP `normal`, который может улучшить скорость загрузок с GitHub; параметр видим и его можно снять перед установкой.

## Версии

- релиз: `v1.2.2`;
- сборка: `1.2.16.0`.

Обновление распространяется единым файлом `FlowsealManager-Setup.exe` и устанавливается автоматически из приложения.
