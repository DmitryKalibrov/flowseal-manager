# Flowseal Manager v1.2.0 — один файл для установки

Выпуск переводит Flowseal Manager на обычную схему «скачал и установил». В GitHub Release теперь нужен только один файл.

## Главное

- единый `FlowsealManager-Setup.exe` вместо ZIP, JSON и отдельного списка хешей;
- автоматический выбор Windows x64 или ARM64;
- установка в `Program Files`, ярлык в меню «Пуск» и штатное удаление через Windows;
- тихое автообновление через тот же файл начиная со следующего релиза;
- проверка размера, SHA-256 от GitHub и версии EXE до запуска;
- настройки, компоненты Flowseal, пользовательские списки и `hosts` не затрагиваются.

## Версии

- релиз: `v1.2.0`;
- сборка: `1.2.14.0`.

## Важно для v1.1.0

В `v1.1.0` ещё используется старая схема ZIP + JSON, поэтому переход на `v1.2.0` нужно выполнить вручную один раз. Скачайте `FlowsealManager-Setup.exe` и запустите его. Все следующие стабильные обновления смогут устанавливаться автоматически.

> Приложение пока не подписано коммерческим сертификатом. Windows SmartScreen может показать предупреждение неизвестного издателя.
