# Flowseal Manager v1.1.0 — автоматическое обновление

Первое обновление в направлении «установил и забыл». Flowseal Manager теперь умеет безопасно получать новые стабильные версии самого приложения из этого GitHub-репозитория.

## Главное

- автоматическая проверка новой версии менеджера при запуске;
- отдельные пакеты для Windows x64 и ARM64;
- проверка размера и SHA-256 до установки;
- повторная проверка подготовленного EXE и плана непосредственно перед заменой;
- установка из отдельного временного процесса после закрытия приложения;
- резервная копия заменяемых файлов;
- автоматический возврат предыдущей сборки, если новая не подтвердит успешный запуск;
- настройки, компоненты Flowseal, пользовательские списки и `hosts` при обновлении не затрагиваются.

## Стандартизация выпусков

- публичная версия релиза: `v1.1.0`;
- внутренняя версия сборки: `1.2.13.0`;
- единый источник номеров: `Directory.Build.props`;
- обязательные файлы релиза: пакеты x64/ARM64, `update-manifest.json` и `SHA256SUMS.txt`;
- автоматическая сборка и проверка через GitHub Actions.

## Важно для обновления с v1.0.0

Версия `v1.0.0` ещё не содержит модуль самообновления, поэтому `v1.1.0` потребуется скачать и запустить вручную один раз. Следующие стабильные версии смогут устанавливаться автоматически.

> Приложение пока не подписано коммерческим сертификатом. Windows SmartScreen может показать предупреждение неизвестного издателя.
