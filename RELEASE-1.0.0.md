# Flowseal Manager v1.0.0 — первый публичный выпуск

Первый публичный выпуск Flowseal Manager объединяет TG WS Proxy и Zapret в одном русскоязычном приложении. В него также входит полноценная работа с официальным файлом `hosts` проекта `zapret-discord-youtube` без ручного скачивания и переноса строк.

## Главное в выпуске

- Новый раздел **«Hosts Zapret»** внутри окна **«Параметры метода»**.
- Проверка наличия и актуальности установленного списка.
- Загрузка официального `.service/hosts` непосредственно из репозитория Flowseal.
- Установка, обновление и удаление списка одной кнопкой.
- Поддержка адресов GitHub, Telegram и Discord из официального списка Zapret.
- Автоматическая очистка DNS-кэша после применения изменений.
- Полностью русский интерфейс нового раздела.

## Безопасное изменение системного hosts

Flowseal Manager хранит список в отдельном помеченном блоке. При обновлении заменяется только этот блок, а при удалении убираются только добавленные менеджером записи. Собственные и сторонние строки в системном `hosts` сохраняются.

Перед каждым изменением автоматически создаётся резервная копия:

`%LocalAppData%\FlowsealManager\backups\hosts`

Если файл повреждён, имеет неподдерживаемый формат или содержит некорректные маркеры, приложение остановит операцию и покажет ошибку без вылета.

## Как использовать

1. Откройте **«Параметры метода»**.
2. Нажмите **«Hosts Zapret»**.
3. Нажмите **«Проверить список»**.
4. Выберите **«Установить»** или **«Обновить»**.

Из этого же окна можно открыть системный `hosts`, перейти к резервным копиям или удалить только список Flowseal.
