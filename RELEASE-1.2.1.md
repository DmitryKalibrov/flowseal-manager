# Flowseal Manager v1.2.1 — поддержка Roblox в hosts

В управляемый список `hosts` добавлен адрес CDN Roblox. Обновление распространяется через единый установщик и поддерживает автоматическую установку из приложения.

## Что нового

- добавлена запись `18.65.39.105 tr.rbxcdn.com` для загрузки ресурсов Roblox;
- запись устанавливается и обновляется вместе с управляемым блоком Flowseal Manager;
- если официальный список когда-либо содержит другую запись для `tr.rbxcdn.com`, менеджер оставляет одно заданное сопоставление без дубликатов;
- перед изменением системного `hosts` по-прежнему создаётся резервная копия;
- пользовательские строки за пределами управляемого блока не изменяются.

## Версии

- релиз: `v1.2.1`;
- сборка: `1.2.15.0`.

После установки откройте раздел `Hosts Zapret` и нажмите `Обновить`, если управляемый блок был установлен ранее.

> Приложение пока не подписано коммерческим сертификатом. Windows SmartScreen может показать предупреждение неизвестного издателя.
