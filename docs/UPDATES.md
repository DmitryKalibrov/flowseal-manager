# Единый файл выпуска

Каждый стабильный GitHub Release содержит ровно один пользовательский файл:

`FlowsealManager-Setup.exe`

Установщик содержит self-contained сборки Windows x64 и ARM64 и выбирает нужную автоматически.

Перед тихим автообновлением менеджер проверяет:

- точное имя файла;
- адрес в релизе нужного GitHub-репозитория;
- размер файла;
- SHA-256, который возвращает GitHub Release API;
- версию релиза и сборки в ресурсах EXE.

Папки `%ProgramData%\FlowsealManager` и `%LocalAppData%\FlowsealManager`, а также системный `hosts` в состав установщика не входят и при обновлении не затрагиваются.
